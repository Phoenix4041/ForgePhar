Como funciona ForgePhar

1. Descomprimir

Sube un archivo .phar o .zip. ForgePhar lo abre en tu navegador, lista todos los archivos que contiene y te entrega un .zip normal con el codigo fuente, listo para editar en tu editor de siempre.

2. Generar .phar

Sube el .zip de la carpeta de tu plugin (debe tener plugin.yml en la raiz, igual que cualquier plugin de PocketMine-MP). ForgePhar arma el .phar con el mismo formato binario que usa PHP: manifest, checksum por archivo y firma. El resultado se descarga directo, listo para subir a tu servidor.

3. Proteger .phar

Hace lo mismo que "Generar .phar", pero ademas:

  • Comprime cada archivo con GZIP (el mismo metodo que usa Phar::compressFiles() en PHP).
  • Elimina comentarios y espacios innecesarios del codigo PHP.

El resultado deja de ser texto plano legible: si alguien abre el .phar con un editor de texto o un zip generico, solo ve binario. Esto no es cifrado irreversible tipo ionCube — eso requiere una extension compilada en el servidor destino y rompe la ejecucion en PocketMine si se intenta falsear. Lo que si obtienes es proteccion real contra la lectura casual de tu codigo.

Privacidad

Nada se sube a ningun servidor. Todo el procesamiento (lectura, compresion, firma) pasa dentro de tu navegador con JavaScript. Puedes desconectarte de internet despues de cargar la pagina y todo sigue funcionando igual.
